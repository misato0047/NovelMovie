# NovelMovie 絵の基準（スタイルガイド）

2026-11-28 に Misato さんと決めた基準。新しい絵を作るときは必ずこれに合わせる。

## 解像度とドット
- 背景・一枚絵は **320×180 ドット** で描く（`formats/style.cfg` に記録。エンジンはこの値で整数倍に拡大する）
- 表示は **横長 6倍（1920×1080）**、**縦長 3倍（960×540、横に余白）**。拡大はニアレスト（ぼかさない）
- キャラの全身は **高さ 150 ドット前後**
- 1ドットの鉛筆で描く。半端な倍率の拡大・縮小はしない

## 見た目（見本：教室に立つパーカーの少女のドット絵）
- 輪郭線は黒ではなく、その部分の暗い色（紺・暗い紫など）
- 陰影は素材ごとに 2〜3 段のベタ塗り。ディザ（網目）はほぼ使わない
- 色数は「そこそこ」。多彩である必要はないが、髪・肌・服・背景で色味ははっきり分ける
- 背景は人物より明暗差と描き込みを控えめにして、人物を浮かせる
- ホラー作品は全体を暗く寒色寄りに。白い着物・肌・黒髪・血の赤は色としてはっきり見せる

## 作り方と分担
1. **台本＋絵コンテ**（Misato）：台本に `#= 番号 場面名` を書き、`tools/conte/make_conte.py` で絵コンテのテンプレートを作る。Krita でラフを描く
2. **キャラ**（Misato）：Krita で普通のラフ（三面図程度、色なし・荒くてよい）。AI を使わず人の手で描く
3. **清書**（Claude）：ラフを目標の大きさに縮小して下敷きにし、1ドットで線を整え、ベタ塗り → 影 2 段 → 色付き輪郭線 → 仕上げ
4. **背景**（Claude）：見本と絵コンテを参照に Magnific（契約内のクレジット）で生成し、320×180 に変換して色調を合わせる
5. **確認**：最初の 1 場面だけ「ラフ段階」と「仕上げ段階」の 2 回。OK が出た 1 枚を基準にして、残りは完成品だけ確認

## 確定したキャラ設定
- **母**（私のお母さんは変わり者）：床まで届く黒髪が体の前後を覆う／前髪の間から赤い片目／袖の広い白い着物と帯／腰から深く曲がった猫背／異様に長い腕。持ち物は出刃包丁のような包丁。三面図は Misato さん作

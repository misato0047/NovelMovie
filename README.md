# NovelMovie（Godot 4.6）

台本テキストを書くだけで、ノベルゲーム風の動画を **横長 16:9（1920×1080）** と **縦長 9:16（1080×1920）** で書き出すためのプロジェクトです。

## 最初に1回だけ

1. このフォルダを Godot 4.6.3 で開く（プロジェクトをインポート）。素材が自動で取り込まれます
2. `_common.bat` をメモ帳で開き、`GODOT=` の行を自分の Godot の exe の場所に書き換える
3. エディタで F5 を押すと、サンプル台本が横長で再生されます

## 使い方

| やりたいこと | 操作 |
|---|---|
| 横長で確認 | エディタで F5、または `preview_horizontal.bat` |
| 縦長で確認 | `preview_vertical.bat` |
| 横長で書き出し | `render_horizontal.bat` |
| 縦長で書き出し | `render_vertical.bat` |
| 両方まとめて書き出し | `render_both.bat` |

- 台本ファイル（.txt）を **bat の上にドラッグ＆ドロップ** すると、その台本で再生・書き出しします。何も渡さなければ `scenario/sample.txt` を使います
- 書き出した動画は `out` フォルダに `台本名_16x9.avi` / `台本名_9x16.avi` で保存されます（30fps、音声入り）
- 書き出しは実時間ではなく1コマずつ正確に行われるので、PCが重くてもコマ落ちしません
- 再生中に Esc で中断できます
- 縦長の書き出しが途中で止まった場合は、フォルダ直下に残った `override.cfg` を削除してください（残っているとエディタでも縦長になります）

## 素材の置き場所

| 種類 | フォルダ | 台本での呼び方 |
|---|---|---|
| 背景 | `assets/bg/` | `@bg ファイル名` |
| 立ち絵 | `assets/chara/` | `名前_表情.png` を `@chara 名前 表情` で呼ぶ |
| BGM | `assets/bgm/` | `@bgm ファイル名` |
| 効果音 | `assets/se/` | `@se ファイル名` |
| ボイス | `assets/voice/` | `@voice ファイル名` |
| フォント | `assets/fonts/` | `main.ttf` か `main.otf` を置くと自動で使う（無ければ游明朝） |

- 拡張子は書きません。画像は png / jpg / webp、音は ogg / wav / mp3 に対応
- 日本語のファイル名も使えます（例：`少女_笑顔.png` → `@chara 少女 笑顔`）
- 素材を追加したら一度エディタに切り替えて取り込ませてから書き出してください
- 素材が見つからないときは止まらずに仮の絵で続行し、画面左上に警告を出します（書き出し時は出ません）

## 台本の書き方

```
# コメント
地の文はそのまま書く
少女「セリフは名前のあとにカギカッコ」
@wait 1.0
```

- 1行が1回の表示です。文字送り → 読み終わるまで待つ → 次の行、と自動で進みます
- 文中に `[color=red]赤文字[/color]` や `[shake rate=18 level=8]震える文字[/shake]` `[wave]揺れる文字[/wave]` が使えます

### コマンド一覧

時間のかかるコマンドは **終わるまで次に進みません**。行末に `nowait` を付けると、終わるのを待たずに次の行へ進みます（例：BGMをフェードインさせながら文章を出す）。

| コマンド | 内容 | 例 |
|---|---|---|
| `@bg 名前 [fade=秒]` | 背景を切り替え（クロスフェード）。`black` `white` `#880000` で単色 | `@bg 廊下_夜 fade=1.5` |
| `@chara 名前 [表情] [pos=位置] [fade=秒]` | 立ち絵を出す。表示中なら表情を差し替え。位置は left / center / right か 0〜1 の数値 | `@chara 少女 無表情 pos=left` |
| `@move 名前 位置 [dur=秒]` | 立ち絵を移動 | `@move 少女 right dur=0.8` |
| `@hide 名前 [fade=秒]` / `@hideall` | 立ち絵を消す | `@hide 少女 fade=0.1` |
| `@say 名前 セリフ` | 名前付きセリフ（カギカッコ不要） | `@say 少女 ねえ` |
| `@voice ファイル名` | 次の行と同時にボイスを再生。ボイスが終わるまで次へ進まない | `@voice s01_001` |
| `@wait 秒` | 待つ | `@wait 1.5` |
| `@fadeout 秒 [color=色]` / `@fadein 秒` | 画面全体の暗転・明転 | `@fadeout 1.0` |
| `@flash [秒] [color=色]` | 画面を一瞬光らせる | `@flash 0.1 color=red` |
| `@shake 秒 [power=強さ]` | 画面を揺らす（標準24） | `@shake 0.5 power=30` |
| `@zoom 倍率 秒 [x=0〜1] [y=0〜1]` | 寄り・引き。x, y は寄る中心。`@zoom 1.0 1.0` で戻す | `@zoom 1.3 2.0 y=0.3` |
| `@noise 量 [fade=秒]` | フィルムノイズ（0〜1） | `@noise 0.3` |
| `@vignette 量 [fade=秒]` | 周辺減光（0〜1） | `@vignette 0.8` |
| `@aberration 量 [fade=秒]` | 色ズレ（0〜3程度） | `@aberration 1` |
| `@glitch 秒 [power=強さ]` | 走査線がずれるグリッチ | `@glitch 0.4` |
| `@bgm 名前 [vol=dB] [fade=秒]` / `@bgmstop [fade=秒]` | BGM（ループ再生）。vol の標準は -8 | `@bgm drone vol=-12` |
| `@se 名前 [vol=dB] [wait=true]` | 効果音 | `@se knock` |
| `@title 文字 [dur=秒]` | 画面中央に大きく文字を出して消す | `@title 第一話 dur=2` |
| `@textbox on/off` | テキスト枠の表示切替 | `@textbox off` |
| `@clear` | テキストを消す | `@clear` |
| `@speed 文字/秒` | 文字送りの速さ（標準20） | `@speed 12` |
| `@autowait 秒` | 1行読み終えてからの待ち（標準1.0） | `@autowait 1.5` |
| `@end` | ここで終了 | `@end` |
| `@cut 名前` | 背景（一枚絵）を一瞬で切り替える。ズームも元に戻る | `@cut oka_clock` |
| `@static 秒 [to=名前] [power=強さ]` | ノイズが走る。`to=` を付けると、ノイズの真ん中で絵を切り替える | `@static 0.5 to=oka_feet` |
| `@blood 秒` / `@blood off [fade=秒]` | 画面の上から血が垂れてくる／消す | `@blood 1.8` |
| `@bigtitle 文字 [fade=秒]` | 画面中央に大きなタイトル（消えずに残る） | `@bigtitle 私のお母さんは変わり者` |
| `@bigtitle_swap 元 新 [color=色] [dur=秒]` | タイトルの文字をノイズとともに差し替える | `@bigtitle_swap 変 化 color=#c42020` |
| `@bigtitle_drop 文字 [dur=秒]` | タイトルの一部を消して、左右を詰める | `@bigtitle_drop わり` |
| `@bigtitle_hide [fade=秒]` | タイトルを消す | `@bigtitle_hide fade=1.5` |
| `@bgmode fit/cover` | 絵を横幅に収める（縦長の標準）／画面を覆う（横長の標準） | `@bgmode cover` |

## 縦長レイアウトについて

縦長では、YouTubeショートやTikTokの画面下部（説明文・ボタン）にかからないよう、テキスト枠を画面の中ほど（上から約58〜78%）に置いています。立ち絵もその上に収まる大きさで表示します。

## 素材の目安サイズ

- 背景：1920×1080 以上（縦長では左右が切れて中央が使われます。縦長専用なら 1080×1920 で作る）
- 立ち絵：背景を透過した PNG、縦長の画像（例 1000×2000）。足元まで描かれているものが自然に収まります

## コードで描く素材（tools/art）

サンプルの背景と立ち絵は `tools/art/make_art.py` がコードで描いています（Python と Pillow / NumPy が必要）。

- 背景は 480×270 ドット、人物は高さ 256 ドット。どちらも画面上では 1 ドット = 4px で表示されます
- 色はほぼ黒〜青灰色だけ、差し色は赤を一点だけ。人物は顔を描かず、輪郭・姿勢・光る目で見せます
- 現在の素材：背景 `corridor_night`、立ち絵 `girl_normal`（赤い片目）/ `girl_down`（うつむき）/ `girl_tilt`（首を傾ける）

## 動画ソフトで編集するためのファイル

書き出すと、動画と一緒に `out` フォルダへ次のファイルができます。

| ファイル | 中身 | 使い道 |
|---|---|---|
| `台本名_16x9.srt` / `_9x16.srt` | テキストの字幕（表示が始まった時刻〜次へ進む時刻） | DaVinci Resolve などに字幕トラックとして読み込む。声を録るときの目安にもなる |
| `台本名_16x9_cues.csv` / `_9x16_cues.csv` | 全コマンドとテキストの時刻一覧 | 場面転換やノイズの位置を確認して、効果音を置く |

- 文字なし版は `render_both_notext.bat`。テキスト枠を出さずに書き出すので、字幕を動画ソフトで自由に付けられます（タイトルの演出は残ります）
- 縦長では絵を横幅いっぱいに収め、その下にテキスト枠（または字幕を置く余白）ができます
- 声を先に録った場合は、`assets/voice/` に入れて台本の行の前に `@voice ファイル名` と書くと、その行は声が終わるまで次へ進みません。声の長さに合わせて映像の尺が決まります
